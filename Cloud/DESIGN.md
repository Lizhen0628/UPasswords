# UPasswords v1 云服务设计

> 当前生产服务由 Cloud/api 的 Go + chi 实现。产品开发版本 v1 不等同于 API 路径版本或同步协议版本。
> 本文描述当前实现；已确认但待实施的 v1 行为以 [决策记录](../DECISIONS.md) 为准。

## 版本约定

| 标识 | 当前含义 |
|---|---|
| 产品开发版本 | v1，本文及项目文档统一采用 |
| HTTP 路径 | 生产只提供 /v1；/v2 已关闭并返回 404 |
| 能力协商 | 生产与当前客户端使用 version: 5；旧协议同步请求会被拒绝 |
| 本地加密容器 | UPWDB2 / UPWKEY1，容器格式版本 2 |
| SQL | Cloud/database/0001_init.sql 为当前初始化 DDL；后续迁移同目录按序维护 |

生产同步数据路由要求请求头 `X-UPW-Sync-Protocol: 5`；缺失、非法或旧版本请求在读取或修改
条目、变更、附件、冲突及 rekey 数据前返回 HTTP 426。账户认证与库目录仍可访问。浏览器扩展
Swift 与浏览器共享客户端已升级为协议 5；卡片 upsert 必须原子提交完整附件引用。客户端也能校验和消费原子裁决事件；四种扩展的本地候选查看/裁决界面已接入，整候选裁决支持附件引用，字段组合仅支持无附件且身份可靠的候选。协议 5 API 与迁移 `0001`–`0010` 已于 2026-10-28 部署；旧客户端不能与新服务同步。新客户端正式分发和跨版本验收仍未完成，服务端部署不代表所有客户端工作已完成。
不要把 /v1 路径解释为同步协议版本 1。

## 密钥与隐私

库主密码不离开设备。它通过 PBKDF2-SHA256 派生密钥打开 .upwkey 信封并取得 VEK；VEK 加密本地库。云同步时每条卡片、标签或个人资料片段由 VEK 使用 AES-GCM 加密，当前客户端 AAD 为该条目的 UUID。服务端只保存密文、摘要、长度、UUID、kind、revision 和时间戳。

账户层与库层分离：邮箱验证码用于云账户授权；库主密码用于解密库。服务端使用 APP_KEK 对邮箱和密码库信封进行应用层保护，email_hmc 用于邮箱查询；会话数据库仅保存随机 bearer token 的 SHA-256 摘要，验证码仅保存键控摘要。

日志只保留操作类型、对象标识、数量、字节数、错误和耗时。禁止记录邮箱、验证码、bearer token、库密钥、密码、字段值、笔记和附件明文。泄露检查只提交 SHA-1 前缀，服务端转发 HIBP 时不记录查询前缀。

## 行级同步

每个云条目由 (vault_id, item_uuid) 唯一标识，客户端持有 revision 作为 CAS 基线。客户端先保存本地加密库，再以批量请求提交脏条目。服务端在事务内验证 baseRevision、写入或删除当前行、追加 item_changes，并推进 vaults.head_seq。

下行先轮询 head_seq，再以游标读取 item_changes。原生客户端以 VEK 加密的共同基线进行三方比较；
持久子项身份可靠且改动互不重叠时合并字段、标签关联和不同附件，再按远端 revision 继续 CAS。
同字段分歧、无法匹配的旧子项身份、删除与本机修改并发仍保护性暂停，不按设备时间覆盖。
只有自动合并失败时，原生客户端才登记加密候选；VEK 域分离 HMAC 指纹保证随机 nonce 重试
幂等，服务端登记时核验现行 revision 或持久删除序号。已部署的 `0005` 迁移新增
`item_tombstones`；墓碑和删除变更在同一事务写入，日志过期后墓碑仍阻止旧 UUID 复活。
迁移只能从仍保留的删除日志回填，已经过期的历史事件不可恢复。

生产 API 的原子裁决会比较 generation、完整候选 ID 集、当前 revision/删除序号，再同事务
提交当前密文或删除、追加一条 `op=resolve` 事件、更新 head_seq 并保留候选 30 天；删除后恢复必须用新 UUID
和为新 AAD 重新加密的条目体。迁移 `0007` 为事件增加 `resolutionType`，区分整候选选择与客户端加密的字段组合结果。
macOS/iOS 已实现整候选裁决及受限字段组合；只有所有候选均可解密、字段 UUID 可靠且无附件时允许组合，
备注必须作为整体选择。含附件候选可完整裁决并在事务内更新附件引用；字段组合仍拒绝含附件候选。
原生端已在改密时将候选内容按固定清单重新加密并更新候选指纹；任一候选不可解密或清单变化会中止改密，保留旧密钥和服务端数据。macOS/iOS 与四种浏览器扩展均支持将活动候选连同附件另存为新条目。
macOS/iOS 对当前密码版本下的单条解密或格式异常已将原始条目载荷以 VEK 加密存入 sidecar，
与数据库快照和游标原子提交后继续同步，并提供设置页重试入口。四种浏览器扩展也已支持单条异常隔离：
使用 VEK 和独立认证数据加密保存异常行，与可读行、游标在同一 IndexedDB 快照中原子提交，
并提供重试入口；若同 UUID 已有可读本地版本则保留该版本，整页异常仍拒绝提交。
服务端及数据库变更已于 2026-10-28 部署，迁移 `0001`–`0010` 已应用；隔离 Go/MariaDB race 集成测试与 vet 于部署前通过。
旧客户端会将 `op=resolve` 当作普通 upsert，删除后恢复到新 UUID 时无法正确收敛，且可能以旧 LWW 重试覆盖裁决。
生产协议 5 门控已启用；旧客户端会在同步数据路由收到 HTTP 426。新旧客户端混合版本验收仍未完成，因此客户端正式发布前必须完成升级与兼容性验证。
服务端变更事件默认保留 90 天；原生游标过期且存在待同步修改或待裁决标记时会阻止自动全量重建。
macOS/iOS 提供“先备份，再采用云端快照”的人工恢复：自包含备份发布成功前不替换本机数据，
备份会保留用于比较、另存或恢复。该流程不承诺设备自动收敛。

macOS/iOS 原生同步状态包括游标、revision、脏修改与删除集合，以及 VEK 加密的共同内容基线，存入 .upwsync 并与数据库快照原子提交。附件基线只保存身份和内容摘要，不重复保存附件字节。浏览器扩展将密文快照与同步状态用 IndexedDB 事务保持一致，解锁期间的 VEK 留在受信任扩展会话存储或后台内存。同步失败不阻止已有本地库使用。

跨设备改密使用 rekey staging：开始任务后暂时拒绝普通写入，客户端上传新 VEK 下的条目密文和附件 DEK 包装，提交时在事务内替换数据、信封并增加 password_version。其他设备检测到 rekey 事件后需使用新密码解锁并重建本地状态。

## 账户与附件

邮箱验证码账户可拥有多个密码库和多设备会话。用户可撤销设备会话；解绑、注销和邮箱转移由敏感操作验证码保护。当前是单用户的个人多设备同步，没有家庭成员、共享库或逐条目授权模型。

生产附件 API 采用暂存上传、校验摘要、登记不可变内容版本和 R2 对象的流程；MariaDB 另以当前引用、删除墓碑及冲突候选引用维护生命周期。`0008_attachment_versions.sql` 建立版本记录，`0009_attachment_purge_state.sql` 增加可重试清理状态。维护任务先在 SQL 事务中标记超期且无当前/冲突引用的版本，提交后删除 R2 对象，再删除版本记录并扣减配额；对象删除或后续 SQL 失败时保留清理状态和配额，供下次重试。普通附件引用、删除/恢复、含附件候选裁决和 R2 清理已部署；原生客户端附件生命周期仍需生产端到端验收。

网站目录由 websites 和 website_domains 提供公开名称、域名映射和图标元数据；图标按摘要寻址存入 R2。站点查询不应把域名写入应用日志。

## API 与运行

公开 API 的当前路径、请求字段及错误行为以[服务端 API 与运维说明](README.md)和 Go 路由实现为准。生产入口为 Cloudflare → Nginx → Go API；MariaDB 通过私网 TLS 访问；每日维护任务执行到期清理、日志保留、附件清扫、计数核对和审计保留。

生产恢复通过回滚到已保存的 Go API 镜像，并在必要时从 MariaDB 备份恢复；R2 对象保存在独立桶中，不随数据库恢复回退。发布、备份与恢复步骤见 [Cloud/README.md](README.md) 和 [api/README.md](api/README.md)。

- 服务端提供只读运营统计，但客户端没有可配置服务器地址或自托管切换流程。

- 附件身份/内容版本、下载优先级及网络策略、20 MiB 单文件与 500 MiB 每库默认额度、
- 保留/清理和恢复规则已确认；不可变附件版本、普通行及候选引用事务、删除/恢复及可重试的两阶段 R2 清理已随迁移 `0008`–`0009` 部署。跨端生产端到端验收仍未完成。
- 冲突候选的密文登记/读取、持久删除证据、generation 与完整 ID 集校验的行级裁决基础及组合结果事件已部署。原生端及四种浏览器扩展已有整候选查看/裁决、候选附件引用和受限字段合成；普通同步行损坏数据已有加密隔离/重试，无法读取的候选支持重新读取，原生端及扩展均支持活动候选连附件另存和候选 rekey。永久损坏候选在原生端以 VEK 独立加密隔离并可重试，四种扩展可导出保留原始密文的保护备份；有待处理修改时的游标超期恢复必须先完成自包含备份，再采用云端快照。旧客户端已被协议门控拒绝同步。
- 自动发布已确定从受信任 main 手动触发、测试后串行部署、显式数据重置和健康检查失败回退镜像；
  不自动反向迁移数据库，workflow 及部署配置待实现。
- 整库备份恢复已确定为独立本地副本，默认不绑定原云端库；可将选中条目以新身份导入当前库，
  v1 不提供整库备份覆盖云端入口。macOS/iOS 客户端现可生成加密备份包，采集可读到的云端附件

  仅作核对，不替代云端候选密文。生产 `/conflict-history` 固定快照分页接口已于 2026-10-28 部署；
