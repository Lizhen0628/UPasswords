# 浏览器扩展

## 职责与边界
Safari、Chrome、Edge、Firefox 共用 `WebExtensions/shared` 的领域模型、加密、同步和 UI 逻辑；平台目录只保留浏览器 API 适配与打包入口。可信扩展页面可读取解锁后的条目，网页侧仅接收用户主动选择的最小填充数据，不得获得完整密码库或备注。持久化缓存只保存密文。

## 条目与填充
登录项可关联多个网站，网站关联以明确的匹配方式决定候选资格；匹配必须限制在安全的 HTTP(S) 页面，不自动提交表单。扩展条目编辑在不破坏原始 XML、附件和未知元数据的前提下提供字段查看、编辑与扩展；无法安全处理的结构应保持只读并提示，不得静默丢弃。

## 条目与网站匹配编辑
登录卡片可将多个 website 字段各自配置为域名、通配符 URL 规则或完整 URL 精确匹配。匹配模式存于该网站字段的 `site-match` 属性，随加密条目正文同步；旧条目缺省按域名模式处理。候选列表、主动填充复核与站点提示必须使用同一共享匹配器，并对非 HTTP(S)、非法规则 fail closed。

创建和详情编辑支持配置网站关联与字段名称、类型和值；修改时按字段稳定 ID 保持身份，新增字段分配新 ID。安全编辑器只改写直接字段和值，保留附件、备注和未知 XML 元数据；无法证明安全的结构保持只读。附件二进制仍不在 popup 中编辑。



## 平台限制
弹窗关闭后不保证草稿保留或后台持续运行。附件内容和部分平台能力可能不适合弹窗编辑；不支持的能力必须告知用户，不能造成数据丢失。
