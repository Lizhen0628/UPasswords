# 浏览器扩展

项目当前开发版本：v1。扩展 API、消息协议与加密容器各自独立版本，按跨端契约说明解释。

Safari、Chrome、Edge、Firefox 共用加密、同步和领域逻辑，界面提供中英文与系统明暗外观。
扩展直接连接账户同步服务，不需要先打开桌面应用。

## 日常使用

1. **登录与解锁**：邮箱验证码登录，选择密码库，再用主密码解锁。已经初始化的本地密文库可离线解锁；首次登录、获取远端密码库和联网保存需要网络。
2. **查找与填充**：在密码库搜索名称、用户名或网站；通过当前网站、收藏筛选缩小范围。点击匹配当前网站的条目即可填充，成功后收起弹窗；其他条目点击查看详情，匹配条目也保留独立详情按钮。填充只向匹配的当前网站发送所选用户名和密码；发送前会检查当前账户/密码库的已知同步冲突，涉及冲突字段时暂停填充，无法取得首次权威清单时也会暂停，离线使用最近一次权威结果。HTTP 页面需要额外确认，不自动提交登录表单。
   注册资料只从当前设备本地解锁的密码库读取；云端目前不接受 kind=3 个人资料记录，因此其他设备和新安装扩展不会通过云端恢复该资料。
3. **复制与打开网站**：列表提供用户名、密码复制入口，详情支持复制字段及打开 HTTP(S) 网站。复制必须由用户主动触发。浏览器弹窗随时可能关闭，扩展不承诺关闭后的定时剪贴板清除；敏感内容复制后请及时覆盖。
4. **生成密码**：生成器使用系统加密随机数，可配置 8–128 个字符与大小写、数字、符号；每个已选择的字符类别都会出现。生成结果可复制，或带入新建登录条目，不保存生成历史。
5. **新建与修改**：可手动新建包含名称、用户名、密码、网站和备注的登录条目；详情可修改现有条目的名称、字段值和备注。保存前再次验证主密码，在本机加密后执行带版本保护的云写入，再提交本地密文快照。
6. **切库与锁定**：顶部切换密码库，切换时清除解锁态和敏感控件；锁定保留账户授权和本地密文。普通退出登录会撤销账户会话但保留加密快照、附件策略和本机所选库；同账户重新登录可继续本地解锁与同步，切换账户不会删除其他账户的本地副本。设置可调整空闲锁定时间。
7. **附件**：设置页可请求下载全部附件或结束该批次，并查看本机可用数量；详情自动优先下载当前条目，支持图片预览、普通文件下载和逐附件“保留离线”。临时失败最多自动重试 5 次并遵守 Retry-After。清理仅针对已确认、可从服务器精确复取且无冲突/离线保护的普通缓存；IndexedDB 以独立策略 store 保存重试和保留状态，并以云端对齐的 attachment_versions/attachments 记录与 attachmentContent 密文缓存保存版本信息，默认预算 256 MiB。弹窗关闭时不承诺持续传输，下次解锁/同步恢复策略。

## 状态与安全边界

- 同步状态区区分同步中、最近成功同步、离线或失败，以及账户授权过期。最近同步时间只表示本次弹窗生命周期内确认的同步，不保证后台持续同步。
- 同步与保存使用快照版本和密码版本校验。冲突、锁定、改密或切库使旧操作失效，不能用迟到的结果恢复明文。
- 当前密码版本下，单条云端记录认证失败或格式不受支持时，扩展以 VEK 和独立认证数据加密保存该密文，在同一 IndexedDB 快照事务中提交隔离记录、同步游标和可读条目；同 UUID 已有可读版本会保留，其他行继续同步。设置页显示隔离原因并提供重试，客户端更新后可重新验证并恢复；整页快照异常仍拒绝提交。
- 草稿、生成密码、主密码不写入本地磁盘存储。弹窗内切换页面或密码库前，未保存的编辑会请求确认；立即锁定始终优先清除草稿。**浏览器直接关闭弹窗时不能保证拦截关闭，未保存草稿会丢失**。
- 确认云端写入成功而本地提交失败时，提示重新解锁并同步，不重复提交。网络响应不明确时不声称已保存，也不自动重试。
- 页面脚本仅获得匹配数量、解锁状态以及用户明确选择填充的最小凭据，不获得完整密码库、原始 XML 或备注。
- 自动填充冲突门控只在本地保存账户/密码库身份、字段 token、冲突代次和检查时间等非敏感状态；候选正文、字段值、密码和密钥不会写入该记录。稳定字段身份无法确认、候选删除或候选无法解密时按条目阻止填充。
- 仅新增 `clipboardWrite` 权限，以便用户主动复制操作跨异步会话校验后可靠写入；不请求剪贴板读取权限。附件图片预览仅允许经过验证的本地 `data:` 图像，不加载远端字体、站点图标或其他视觉资源，不增加默认自动填充／自动提交。
- Firefox 的同步服务网络权限按需申请；拒绝授权不妨碍使用已初始化的本地密文库。

本轮范围不包括：登录提交捕获与自动保存提示、网站改密捕获、TOTP 生成／填充、Passkey、银行卡／地址填充、标签管理、完整附件历史备份及离线写入。备份导入与加密独立本地副本已实现，但完整历史采集仍受云端清单和保留期限制。
收藏筛选用于显示原生端标记的收藏条目，不代表扩展提供完整收藏／标签编辑。

## 构建与加载

在仓库根执行：

```bash
pnpm install
pnpm build
pnpm test
```

- Chrome：在扩展管理页开启开发者模式，加载 `WebExtensions/chrome`；源码更新并构建后点击“重新加载”。
- Edge：加载 `WebExtensions/edge`，更新方式与 Chrome 相同。
- Firefox：在 `about:debugging` 临时加载 `WebExtensions/firefox/manifest.json`；更新后重新加载临时扩展。
- Safari：执行 `./scripts/make-app.sh`，构建并更新独立 Safari 容器，再在 Safari 扩展设置中启用。Safari 的网站访问授权仍由用户管理。

`src/shared/` 是共享 TypeScript 的构建拷贝，不要手工编辑。

## 手工验收

使用专门的测试账户和测试条目，不把真实密码、验证码、主密码或条目内容粘贴进日志、截图或缺陷报告。

- 中英双语、明暗外观：检查登录、选库、解锁、密码库、详情、编辑、新建、生成器、设置，按钮可由键盘操作且滚动区域可达。
- 查找：按名称、用户名、域名搜索；密码、秘密和备注不能被搜索命中。当前网站筛选排除其他网站；收藏筛选只显示已收藏条目；无结果时有可操作引导。
- 填充：同站点填写用户名／密码，不自动提交；外站条目不能填入当前页；浏览器内部页面不能填充；HTTP 页面取消确认后不发送凭据。
- 复制：只复制所选字段，成功／失败有反馈；不显示或记录所复制的内容。
- 生成：调整长度及字符类别，关闭全部类别时有校验；重新生成、复制、带入新建均有效；锁定后生成结果与新建草稿清空。
- 新建：从当前网站预填网站信息，不读取网页密码；保存要求主密码。创建后条目可被列表检索，原生 App 同步后字段与备注正确。
- 编辑：保留未修改字段、附件和未知 XML 元数据；保留搜索与滚动上下文；未保存时切页请求确认，取消后草稿不丢失。
- 切库：切换后重新解锁；旧库条目和生成密码不残留；取消选库能回到原绑定库但不能绕过解锁。
- 附件：设置页请求下载全部后校验缺失计数，已缓存版本不得在批次完成前被预算清理；手动结束只释放批次保护。验证临时失败遵守 Retry-After、重开弹窗不重置次数、手动重试开启新一轮。验证 256 MiB 预算只清理服务端准确版本可复取且无冲突/离线保护的 LRU 字节，空间不足不清理任何已有文件；锁定和登出取消传输，迟到结果不得提交。
- 并发：保存或同步中锁定、切库、另一端修改／改密，迟到结果不能恢复明文或覆盖新版本。已保存但本地提交失败时不重复 POST。
- 损坏记录：一条增量记录认证失败时，其余有效变化和游标继续原子提交；隔离加密或缓存提交失败时游标不得前移；锁定、切库及重开弹窗不得泄漏旧库隔离状态；升级后重试不能覆盖更高 revision 的本地内容。
- 退出登录：账户会话撤销后，加密快照、附件策略及所选库绑定仍保留；同账户重新登录可从本机解锁，切换账户不会清除旧账户缓存；登出前启动的同步任务不能跨 epoch 写回旧会话。
- 备份：四端从本地密文缓存生成原生兼容 `.upwbackup`，尝试采集并校验云端附件版本和未解决/保留冲突候选，导出前重查云端清单；解锁密钥仅留在可信后台。可导入备份并创建加密的独立本地副本；副本不参与自动填充或云同步。清单或历史不完整时须明确确认后才恢复。活动冲突候选可连同附件另存为独立条目，含附件候选可完整裁决；候选永久损坏时可导出保护备份，备份保留原始密文并明确标记不完整。浏览器端字段组合以所有候选可解密、字段 UUID 稳定且不含附件为前提。

自动测试覆盖共享密码生成、原生兼容 XML、创建／更新协议验证，以及四端弹窗的会话、竞态、保存和交互回归；不替代真实浏览器的交互验收。
